1. INTRODUCTION                                               *aigent-intro*

aigent.nvim is a fast, intent-driven LLM assistant for Neovim supporting
both cloud (AGY CLI) and local (Ollama / OpenAI-compatible) backends.
It features built-in NeoMutt email safety, header detection, and a
Telescope picker with live preview.

==============================================================================
2. CONFIGURATION                                             *aigent-config*

Call setup in your init.lua / lazy spec:
>lua
    require("aigent").setup({
        provider = "ollama",
        auto_mail_agy = true,
    })
<

==============================================================================
3. COMMANDS                                                 *aigent-commands*

:Aigent [prompt]            Open picker or run with specific prompt
:AigentPrompt               Open Telescope prompt picker with live preview
:AigentProvider             Open Telescope provider dropdown picker
:AigentToggleProvider       Toggle default provider (Ollama <-> AGY)

==============================================================================
4. KEYMAPS                                                   *aigent-keymaps*

<leader>ag                  Open prompt picker and execute on <CR>
<leader>ap                  Select provider via Telescope dropdown
